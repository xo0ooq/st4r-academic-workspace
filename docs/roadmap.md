# Roadmap

## Available in prototype 0.1.0
- In-memory academic task CRUD (create/list/complete/delete)
- Optional course and due date fields
- API health endpoint, tests and CI

## Proposed — not implemented
- Persistent storage and migrations
- Authentication and authorization
- Multi-user collaboration and assignment
- Google Classroom, Drive and Gmail connectors, subject to API permissions
- AI-assisted task summaries and classification (optional, privacy-aware)
- Rate limiting, monitoring and security review

No claims are made about production use, users or ecosystem adoption.
