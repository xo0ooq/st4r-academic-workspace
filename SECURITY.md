# Security policy

ST4R 0.1.0 is an experimental prototype and **not production ready**. It has no user authentication, authorization, persistent storage or external integrations. Do not expose it to the public internet or store personal/student data in it.

If you find a vulnerability, please avoid posting exploit details in a public issue. Contact the repository maintainer privately using GitHub's security advisory reporting feature, if enabled, or request a private contact method.

Supported versions: no production versions are currently supported. Security issues will be assessed on a best-effort basis.
