# Contributing to ST4R

ST4R is an early-stage experiment. Contributions, reproducible bug reports and documentation improvements are welcome.

1. Open an issue to discuss significant feature changes.
2. Fork the repository and create a focused branch.
3. Set up with `python -m pip install -e '.[dev]'`.
4. Run `python -m pytest -q` before opening a pull request.
5. Describe your changes and any security or privacy impact.

Do not submit passwords, access tokens, student records or other sensitive data.
